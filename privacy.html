Privacy, simply.

Effective September 20, 2026 · X Focus Mode 1.0.0

X Focus Mode is a Chrome extension that changes how X is displayed in your browser. It works with the X page you already have open and does not require a separate account.

What happens on your device

The extension reads the posts, author display names and usernames, avatars, media elements, navigation links, controls, and current page URL already present on supported x.com and twitter.com pages. It uses them locally to provide its reading layout, search navigation, bookmarks view, and keyboard controls. This page content is not sent to the developer or to an extension server.

Your reading preferences—such as enabled status, text size, appearance, pinned navigation, engagement-count visibility, and whether you have seen the first-use hint—are stored locally using Chrome’s extension storage. They are not synced by this extension to another device.

Local use, no developer collection

The Chrome Web Store disclosures cover website content, names/usernames (personally identifiable information), and the current X page URL (web history). This information is handled locally only to display the reader and identify the current view. The extension does not keep a browsing-history log, access Chrome’s browsing-history database, or retain a copy of posts or author information after the page is closed.

X Focus Mode does not transmit this page information to the developer, sell it, or share it with unrelated services. It does not collect passwords or private messages, and it does not log reading activity or keystrokes. It has no analytics, advertising SDK, tracking pixels, or developer-operated backend. It does not request access to passwords, cookies, downloads, or browsing history.

Limited use

X Focus Mode’s use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Local page information is used only for the stated reading features. It is never used for advertising, profiling, creditworthiness, or lending decisions. The developer does not receive or read this information.

Your actions on X

Searches, likes, bookmarks, replies, and other actions continue to use X’s own pages and controls. X receives and handles those actions under its own policies. The extension does not create a separate copy of your timeline or saved posts.

Permissions

Storage: saves your reading preferences on this device. Page access on x.com and twitter.com: lets the extension adjust the displayed page and connect its reading controls to X’s existing interface. The extension does not run on unrelated websites.

The website

This website contains no analytics, account system, or tracking cookies. It is hosted on GitHub Pages. GitHub processes standard connection information, such as IP addresses, when serving the site; see GitHub’s privacy statement. Links to X, GitHub, and the Chrome Web Store are governed by those services’ policies.

Your control

You can turn the reading interface off with F or the menu switch. Removing the extension removes its local extension storage. Optional troubleshooting logs stay in your browser’s developer console and are disabled by default.

Questions or updates

For support or privacy questions, open an issue in the project repository. Do not include private account data in a public issue. Any changes to this policy will be published here with an updated date.

X Focus Mode is independent of, and is not affiliated with or endorsed by, X Corp. or Google.
