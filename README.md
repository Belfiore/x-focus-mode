# X Focus Mode

A quieter reading experience for X.

Website: https://belfiore.github.io/x-focus-mode/

This repository contains the public website and extension download. The Chrome Web Store listing will be linked from the website when the submission has an assigned listing URL.

## Extension

X Focus Mode gives your existing X timeline spacious posts, adjustable type, Black/White appearance, pinned navigation, and a styled bookmarks view. Press F to return to regular X; use the arrow keys to move between posts.

The extension only stores local reading preferences. It has no analytics or backend. See the website’s privacy page for details.

## Support

Open a GitHub issue with steps to reproduce the problem. Avoid posting private messages, account identifiers, or other sensitive information.
